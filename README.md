# Leonid Serguei

Etudiant en informatique, curieux de systemes, de Linux et de developpement web.

Je construis des projets pour apprendre proprement: comprendre le fonctionnement bas niveau, structurer des APIs, soigner les interfaces et documenter ce que je decouvre.

## Ce que je travaille

- Backend: Python, Django REST Framework, FastAPI, Express, PostgreSQL/MySQL
- Frontend: Vue, Tailwind CSS, interfaces responsives et dashboards d'administration
- Systeme: Linux, reseau, automatisation, troubleshooting et bases DevOps
- IA appliquee: petits modeles, APIs de classification et interfaces de demonstration
